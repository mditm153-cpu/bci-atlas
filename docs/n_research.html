원문 검증표 사용 방법
① 관리자 PC에서 ‘N 원문 검증표 열기’로컬 전용
② DART 원문으로 계약금액·기간·변화 사실 확인사실 검증
③ 이익 증가 가설과 반례를 각각 기입예측 분리
④ fact_checked=Y, public_approved=Y인 건만 공개 검토정보에 반영명시적 승인
⑤ PC ‘공개 웹 게시’를 누르면 화면 갱신재게시

검토표의 ‘강화’는 정성적 투자 가설 평가이지 CAN SLIM N 최종 매수 판정이 아닙니다. 신규 수주에서 기존 수주의 정정·연장·단순 재계약은 신규 이익으로 자동 가산하지 않습니다. 신고가나 RS는 별도의 수정주가·거래량 검증이 필요합니다.

자료: DART 공시검색 및 운영자가 원문 검증 후 공개 승인한 검토 메모. 허가되지 않은 KRX 주가 원시자료와 RS는 공개하지 않습니다. N 자동 확정·매수 신호 없음.
