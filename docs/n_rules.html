윌리엄 오닐의 원칙을 국내 DART 공시 분석에 적용하기 위한 BCI 연구 규칙

전체 상황판N 공시 목록전략 성과
핵심 판단: N은 계약금액이 크다는 사실만으로 충족되지 않습니다. 새로운 사업 변화 + 이익 증가의 증거 + 지속 가능성을 확인하고, 오닐이 중시한 신고가·유효한 차트 기반과 강한 수요는 가격·거래량에서 별도로 검증합니다. 원문 검토만 마친 기업은 최종 매수 대상이 아닙니다.

1. BCI N의 5단계 판정

01 / DETECT
공시 제목 포착

신제품·공급계약·신시장·설비투자·경영 변화를 자동 분류

조사 대상 · N 통과 아님
02 / VALIDATE
원문 사실 검증

신규/정정/연장 구분, 계약 상대방, 금액, 기간, 취소 조건, 이사회 결정

원문 확인
03 / ECONOMICS
이익으로 이어지는가?

기존 매출 대체인지 순증인지, 증분 영업이익, 운전자본, 신규 매출 실현

가정·사실 분리
04 / DURABILITY
1~3년 지속되는가?

재구매·후속 고객·기술 해자·생산능력·고객 집중·재무건전성

성장동력 근거 강화 가능
05 / MARKET
시장이 인정하는가?

수정주가 기준 신고가·유효한 베이스와 돌파 거래량·RS를 별도 검증

N 가격·S·L 교차 검증
FINAL / DECISION
CAN SLIM 전체를 통과하는가?

C·A·N·S·L·I·M을 모두 확인하고 계좌 허용 손실을 계산한 뒤 진입 판단

현재 자동 매수확정 기능 없음

3. 공시 유형별 판별 기준

공시 유형반드시 확인할 증거주의해야 할 함정
대형 수주신규 계약 여부, 인식 일정, 고객, 증분 매출·마진, 후속 발주장기계약 금액을 1년 매출로 오해, 반복 공시 중복
신제품·서비스실제 출하·유료 고객·양산 개시·기존 제품 대비 경쟁력개발 발표·전시 참가만으로 이익 증가 단정
새 시장 진출첫 고객·유통망·인허가·해외 매출 실적법인 설립이나 MOU를 매출로 간주
설비투자가동률·투자수익률·자금조달·고객 물량 확보투자금 자체를 미래 매출·이익으로 간주
경영·산업 변화실제 경영 개선, 가격 결정력, 경쟁 환경 변화, 비용 구조대표 교체·산업 뉴스만으로 수혜 확정
신고가수정주가, 적절한 베이스, 유효한 돌파, 거래량·시장 환경액면분할 착시·급등 추격·부실주 단기 신고가

4. BCI의 연구용 스크리닝 규칙

N 실질성 신호 (내부 연구 가설)

공급계약 우선검토계약기간 안분액 / 전년 매출 ≥ 10%
수익 기여 우선검토향후 영업이익 순증 가능성과 근거
제품·시장 변화첫 판매·반복 고객 등 상용화 증거
반증 탐색취소·희석·차입·운전자본 위험

10%는 공시 조사 우선순위를 정하기 위한 BCI 임시 가설입니다. 오닐의 공식 N 합격 기준이 아니며, 백테스트로 타당성을 검증해야 합니다.
